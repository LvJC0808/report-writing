# DOCX 实验报告 Skill 设计

## 目标

创建一个辅助生成 `.docx` 实验报告的 Codex skill。用户提供 `.docx` 报告模板和实验材料文件后，skill 先解析模板格式，再读取材料生成摘要、缺失项和报告大纲。用户确认大纲后，才生成最终 `.docx` 报告。

skill 的核心原则是：复用模板格式、基于材料写作、生成前先审核大纲、不能编造实验结果。

## 输入

必需输入：

- `.docx` 报告模板

优先支持的材料输入：

- 实验指导书
- 代码文件
- README 或运行说明
- 运行日志
- 结果数据
- 截图或图片
- 已有报告草稿

备用输入：

- 用户在对话中粘贴实验材料

## 核心流程

1. 解析模板格式

   优先查找模板中的明确格式说明。如果没有说明，就从实际段落、标题、表格、题注、页眉页脚中推断格式。

2. 生成格式档案

   输出 `format-profile.json`，记录标题层级、编号规则、字体字号、正文样式、表格文字、图片题注、页眉页脚、页面设置等。

3. 处理个人信息

   检测姓名、学号、班级、日期、实验名称、课程名称、指导教师等字段。检测到后，一次性列出所有字段，并询问用户是否填写。

   用户可以只填写部分字段。未提供的字段保留原占位符或原空白格式。skill 不得根据上下文猜测个人信息。

4. 读取实验材料

   按文件类型分类提取事实、代码逻辑、实验要求、结果数据、截图说明和可改写草稿。

5. 生成材料摘要和缺失项

   输出 `material-summary.md` 和 `missing-info.md`。重要事实尽量标注来源文件。

6. 生成报告大纲

   输出 `report-outline.md`。默认必须等待用户确认大纲。

7. 生成最终 `.docx`

   默认复制模板生成新报告。如果无法安全写入，则从空白文档按格式档案重建。

## 内容生成边界

允许自动整理和改写：

- 实验目的
- 实验原理
- 实验步骤
- 环境配置
- 代码说明

必须严格依赖材料或用户确认：

- 实验结果
- 性能数据
- 截图说明
- 对比结论

缺少结果材料时，skill 不能编造结果，只能留占位、标记待补充，或询问用户补充实验结果。

实验结论必须基于已有结果材料。没有结果材料时，不能写确定性结论。

## 默认格式规则

当模板没有足够信息时，采用以下默认规则：

- 正文设置四级标题
- 各级标题字体均为黑体
- 一级标题字号为四号
- 其余各级标题字号为小四号
- 一级标题编号为“一、”“二、”
- 二级标题编号为“（一）”“（二）”
- 三级标题编号为“1.”“2.”
- 四级标题编号为“（1）”“（2）”
- 正文插图、表格中文字字号为五号

## DOCX 写入策略

默认采用模板副本生成新报告：

- 复制模板为新文件
- 保留页面设置、页边距、页眉页脚、页码、已有表格结构和样式定义
- 在识别出的正文区域写入报告内容
- 尽量复用模板已有段落、标题、表格和图片题注格式

如果模板结构复杂、正文区域无法可靠定位，或直接写入会破坏结构，则降级为从空白文档重建报告：

- 从模板提取格式档案
- 新建 `.docx`
- 按格式档案重建标题、正文、表格、图片和题注
- 尽量复用页边距、字体字号、编号规则等可提取信息

## 个人信息规则

检测到个人信息字段时，必须先询问用户是否填写。

询问方式：

- 一次性列出所有检测到的字段
- 让用户按字段名提供内容
- 允许用户留空部分字段

写入规则：

- 复用原位置的字体、字号、表格单元格、制表位或下划线
- 未填写字段保留原样
- 不自动猜测姓名、学号、班级、日期、实验名称等个人信息
- 只有模板本身靠空格排版时，才按中英文和数字宽度估算补空格

## 中间文件

skill 应生成这些审核中间文件：

- `format-profile.json`
- `material-summary.md`
- `missing-info.md`
- `report-outline.md`

这些文件用于让用户在生成 `.docx` 前确认格式理解、材料来源、缺失信息和报告结构。

## 失败处理

- 模板格式无法充分识别：输出推断项和未知项，询问用户确认。
- 材料不足：生成缺失项清单，不编造内容。
- 个人信息缺失：保留占位。
- 模板写入风险高：提示用户并降级为格式重建模式。
- 图片或表格无法自动放置：标记位置并询问用户。

## 推荐实现形态

采用 `SKILL.md + 少量脚本 + 审核中间文件`。

`SKILL.md` 定义交互流程、格式推断规则、内容生成边界和失败处理。脚本负责稳定处理可自动化的部分，例如：

- 解析 `.docx` 样式和编号
- 提取模板中的候选标题和正文格式
- 复制模板并生成新报告
- 写入标题、正文、表格和图片

初版不追求全自动一键生成，应优先保证格式可控、事实不编造、用户能在生成前确认大纲。
